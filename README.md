# Painel Pé de Serra

Página estática com dados criptografados por usuário. Abra `index.html` pelo link do GitHub Pages.

Publicar: crie um repositório, envie o conteúdo desta pasta (index.html, README.md e a pasta data) e ative Settings > Pages > Deploy from a branch > main / (root).
Atualizar no fechamento do mês: substitua os arquivos da pasta `data`.
